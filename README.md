## Day 01: Cybersecurity Basics

### 1. The CIA Triad

The CIA Triad is a fundamental information security model consisting of three principles:

| Principle | Definition | Example |
|---|---|---|
| Confidentiality | Ensuring information is accessible only to authorised individuals. | Encryption and MFA |
| Integrity | Ensuring information remains accurate and is not modified without authorisation. | Hashing and digital signatures |
| Availability | Ensuring systems and information remain accessible when required. | Backups and redundancy |

**Real-world example:**

At a police checkpoint, an officer suspects that a vehicle's registration documents are forged. This raises concerns about integrity because the authenticity and accuracy of the information cannot be trusted.

### 2. Threat vs Vulnerability vs Risk

| Concept | Definition | Example |
|---|---|---|
| Threat | A potential danger that could cause harm to an asset. | A cybercriminal |
| Vulnerability | A weakness that could be exploited. | An outdated operating system |
| Risk | The potential for loss or damage when a threat exploits a vulnerability. | A data breach resulting from an unpatched server |

### 3. What is a Security Operations Centre (SOC)?

A Security Operations Centre (SOC) is a centralised team responsible for continuously monitoring, detecting, analysing and responding to cybersecurity threats affecting an organisation's IT infrastructure.

Its primary purpose is to protect networks, systems, applications and sensitive information.

Key responsibilities:
- 24/7 security monitoring.
- Threat detection and alert investigation.
- Security incident response.
- Vulnerability monitoring.
- Threat intelligence analysis.
- Security reporting and documentation.

### 4. SOC Analyst Levels

| Level | Responsibilities |
|---|---|
| L1 – Tier 1 Analyst | Monitors security alerts, performs initial triage, identifies suspicious activity and escalates incidents. |
| L2 – Tier 2 Analyst | Conducts deeper investigations, analyses evidence, determines incident scope and performs containment activities. |
| L3 – Tier 3 Analyst | Handles complex investigations, advanced threat analysis, detection engineering and security improvements. |

**Additional SOC roles:**

- Incident Responder: Investigates and manages security incidents, including containment, eradication and recovery.
- Threat Hunter: Proactively searches systems and networks for hidden threats that automated security tools may not detect.

### 5. Blue Team vs Red Team

| Blue Team | Red Team |
|---|---|
| Focuses on defence. | Focuses on authorised offensive security testing. |
| Monitors networks and systems. | Simulates attacker techniques. |
| Detects and investigates threats. | Identifies security weaknesses. |
| Responds to incidents. | Tests organisational security controls. |

Both teams contribute to improving an organisation's security posture.
